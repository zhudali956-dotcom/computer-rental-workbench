# 销售工作台 P0 实施计划

依据《电脑租赁_AI运营工作台_建设方案_V1.1_优化稿.md》。使用 Node.js、SQLite、React 与同源 Web 服务。工作区是新目录，直接在当前目录实现。

- [x] 销售底座。`server/store.mjs` 管理身份、持久化线索和原子事务。测试覆盖重复导入、并发竞争、员工越权、拒绝联系和备份恢复。
- [x] 录入与飞书。`server/import.mjs` 解析 CSV/XLSX、映射列并保留行号。`server/feishu.mjs` 按业务键和快照核对后写入。模拟接口验证写入前不可领取、回执丢失不重建、远端手改进入冲突。
- [x] 网页。`server/index.mjs` 提供同源认证与业务接口，`src/` 提供销售、导入、员工、统计和异常界面。`checks/browser.mjs` 验证独立浏览器会话、回执丢失后的重试和完整业务操作。
- [x] 本机演示交付。README 记录启动、飞书配置、恢复与真实联调所需条件。
- [ ] 真实业务验收。后续加入 RPA 脱敏样表、飞书测试表及办公室主机，实测字段、数据权限、双员工试跑和恢复时限。

P0 使用演示库验证独立闭环，正式模式须配置飞书并通过字段和权限校验。后续内容、发布和评论按方案在 P0 业务试跑后推进。测试样表不代表真实 RPA 结构。
